# 🌐 Conecta Fácil — Guia Digital de Inclusão Digital

**A tecnologia fica mais fácil quando o conhecimento é compartilhado!**

O **Conecta Fácil** é um projeto desenvolvido com o objetivo de promover a inclusão digital, oferecendo orientações simples, práticas e acessíveis para pessoas que desejam aprender a utilizar melhor a internet, o celular e o computador.

A plataforma foi criada para facilitar o acesso ao conhecimento tecnológico, ajudando iniciantes a desenvolverem habilidades digitais e utilizarem os recursos da internet com mais segurança e autonomia.

---

## 🎯 Objetivo do Projeto

Promover a inclusão digital por meio de um guia educativo e interativo, permitindo que pessoas com pouca familiaridade com a tecnologia aprendam a utilizar ferramentas e serviços digitais no dia a dia.

## ✨ Funcionalidades

O site oferece diferentes recursos de aprendizagem:

- 📱 **Orientações sobre celulares:** dicas para utilizar recursos básicos do celular.
- 💻 **Orientações sobre computadores:** conteúdos para iniciantes.
- 🌐 **Acesso à internet:** instruções para navegar na internet.
- 📶 **Conexão Wi-Fi:** tutorial para conectar dispositivos a redes sem fio.
- 🔎 **Pesquisas na internet:** dicas para realizar pesquisas de maneira eficiente.
- 📧 **Utilização de e-mail:** orientações para criar e enviar mensagens.
- 📁 **Arquivos e documentos:** instruções para baixar e localizar arquivos.
- 📸 **Compartilhamento de fotos:** orientações para compartilhar imagens com segurança.
- 🔐 **Segurança digital:** dicas para proteger informações pessoais e evitar golpes.
- ❓ **Perguntas frequentes:** respostas para dúvidas comuns.
- 🧠 **Quiz interativo:** teste de conhecimentos com 12 perguntas e explicações.
- ♿ **Acessibilidade:** opções para aumentar ou diminuir o tamanho do texto e ativar o alto contraste.

| Tecnologia | Utilização |

## 📂 Estrutura do Projeto

```text
Conecta-Facil/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

**Descrição dos arquivos:**

- `index.html`: contém a estrutura e os conteúdos do site.
- `style.css`: responsável pelo design, cores, organização e adaptação para diferentes telas.
- `script.js`: responsável pelas funcionalidades interativas.
- `README.md`: apresenta informações sobre o projeto e sua utilização.

## 🚀 Como Executar o Projeto

Não é necessário instalar programas ou configurar servidores para visualizar o site localmente.

1. Baixe ou clone este repositório.
2. Extraia os arquivos, caso estejam compactados.
3. Abra a pasta do projeto.
4. Localize o arquivo `index.html`.
5. Clique duas vezes nele para abrir no navegador.

Pronto! O Conecta Fácil estará disponível para utilização.

## 🌍 Público-Alvo

O projeto é destinado principalmente a:

- Pessoas com pouca experiência em tecnologia.
- Iniciantes no uso de computadores e celulares.
- Pessoas que desejam aprender a utilizar a internet.
- Pessoas que precisam de orientações sobre segurança digital.
- Membros da comunidade que desejam desenvolver sua autonomia digital.

## 🤝 Impacto Social

A inclusão digital é importante para ampliar oportunidades de aprendizagem, comunicação e acesso à informação.

O Conecta Fácil busca contribuir com a comunidade por meio de conteúdos educativos, linguagem acessível e orientações práticas, incentivando o uso consciente e seguro da tecnologia.
